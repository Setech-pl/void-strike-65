# Diagnostics

Each file here is a dated report of one proof, measurement, fix or rejected
experiment, bound to the checkpoint and artifact it names.

Diagnostics are **historical evidence**. They are not rewritten to match later
architecture, and they do not override:

- current Git, code and build output;
- [../STATUS.md](../STATUS.md);
- the current roadmap [../plan-realizacji.md](../plan-realizacji.md);
- the current rules [../reguly-projektu.txt](../reguly-projektu.txt).

A "next task" or recommendation inside a diagnostic is historical unless STATUS
or the current plan repeats it. See the precedence list in
[../README.md](../README.md).
