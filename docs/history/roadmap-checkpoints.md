# Roadmap checkpoints

The project previously tracked work as branch-specific evidence cards. The
following sequence is retained for provenance, not as the current queue:

1. loader, frontend, fixed HUD, starfield, and broadside sector;
2. Interceptor descriptors, combat behavior, pulse weapon, and collision gates;
3. player lives, hull damage, respawn, Game Over, music, and pause;
4. entity/effects foundation;
5. debris polish, destructible debris, and breakup effects;
6. runtime payload compaction;
7. Rapid Fire Booster;
8. Spread Shot Booster and its backing/erase visual correction.

At several checkpoints the next feature was described as entity/effects
foundation or debris work. Those statements were correct only at the time and
are superseded by [roadmap-2026-09-15.md](roadmap-2026-09-15.md).
